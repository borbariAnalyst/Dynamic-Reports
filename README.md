# 📊 Dynamic Excel Reporting System
A fully automated, interactive Excel reporting solution built using Power Query, Data Validation, and modern Dynamic Array Functions. This project demonstrates how Excel can be transformed into a lightweight analytical engine capable of refreshing, filtering, and reshaping data without manual intervention.

## 🚀 Project Overview
This report was designed to turn raw CSV data into a clean, dynamic, and user friendly analytical tool. The workflow combines:
- 	Power Query for automated data ingestion and transformation
-	Data Validation for controlled user inputs
-	Dynamic Array Functions for responsive reporting
-	Error handling logic to ensure stability and usability

The result is a report that updates itself, responds instantly to user selections, and delivers insights with zero manual effort.
🔧 Tools & Techniques Used
### Power Query (ETL Pipeline)
-	Connected directly to a CSV file
-	Cleaned and transformed raw data
-	Standardised column types
-	Built a repeatable refresh process
-	Ensured the report always reflects the latest data
### Data Validation
-	Created dropdown selectors for country and category
-	Prevented invalid inputs
-	Ensured all formulas receive clean, structured values
-	Improved user experience and reduced errors
  
### Dynamic Excel Functions
This project uses several modern Excel functions to build a flexible reporting model:
Function	Purpose
- UNIQUE:	 Generate dynamic lists for dropdowns and filters
- SORT: 	Automatically rank and order results
- FILTER:	Create responsive views based on user selections
- GROUPBY:	Aggregate data without pivot tables
- CHOOSECOLS:	Reshape datasets for cleaner layouts
- TAKE:	Extract top N insights dynamically
- IFERROR:	Keep the model stable and user friendly
## 📈 Key Features
- Automated Data Refresh
  With Power Query, the report updates itself with one click — no copy/paste, no manual imports.
- Interactive Filtering
  Users can select regions, categories, products, or channels using validated dropdowns.
- Dynamic Insights
  The report recalculates instantly using dynamic arrays, surfacing:
-	Top performing products
-	Regional trends
-	Category breakdowns
-	Salesperson performance
-	Revenue summaries
- Clean, Error Resistant Design
IFERROR and Data Validation ensure the report remains stable even when filters return no results.

### 📁 Dataset
The dataset used in this report was generated programmatically and loaded via Power Query from a CSV file.
